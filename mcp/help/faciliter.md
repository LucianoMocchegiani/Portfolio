# Faciliter

Producto propio. https://faciliter.xyz/

SaaS multi-tenant de afiliaciones en Argentina (gyms, clubes, estudios): afiliados, packs, caja (Mercado Pago + efectivo), puerta QR, app del socio. El acceso SSI usa Kuatia (issuer/verifier compartidos).

Rol: Software Engineer. Stack: NestJS, Next.js, Flutter, PostgreSQL, Redis, chat-api + MCP.

Qué construí: API, panel Admin, app, caja y puerta, asistente de consulta.
